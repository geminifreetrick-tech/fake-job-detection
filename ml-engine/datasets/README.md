# Datasets

## `sample_jobs.csv`
Synthetically generated training data (1 000 rows, 60 % legit / 40 % fraud).
Generated by `generate_dataset.py` using template strings seeded for
reproducibility (`random.seed(42)`).

**Columns:**
| Column    | Type      | Description |
|-----------|-----------|-------------|
| `title`   | string    | Job posting title |
| `company` | string    | Company name (may be blank for some scam rows) |
| `text`    | string    | Full posting body text |
| `label`   | int (0/1) | 0 = legit, 1 = fraudulent |

### Limitations
- Template-derived; vocabulary is narrow.
- Does not represent real-world distribution. Intended only for demonstration
  and integration testing of the ML pipeline.
- For a production model, use the [Employment Scam Aegean Dataset (EMSCAD)](https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction) or an equivalent labeled corpus.

## `scam_lexicon.tsv`
Hand-curated phrases commonly found in fraudulent postings, each with a
numeric weight reflecting signal strength.

## `common_words.txt`
Small English word list used for OOV ratio computation by the grammar
feature extractor.

## Regenerating the CSV
```bash
cd ml-engine
python datasets/generate_dataset.py
```
